WORKED EXAMPLE (math done, verify): 3 debts, $250/mo extra toward payoff
- Card A: $2,000 @ 24%
- Card B: $6,000 @ 21%
- Card C: $1,000 @ 15%
Snowball order (smallest balance first): C ($1k) -> A ($2k) -> B ($6k)
Avalanche order (highest APR first): A (24%) -> B (21%) -> C (15%)
Avalanche saves the most interest; snowball gives faster first win (motivation).
